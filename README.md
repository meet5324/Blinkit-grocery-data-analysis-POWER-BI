# Blinkit-grocery-data-analysis-POWER-BI
  📦 Blinkit Sales Data Analysis with Power BI
  This project presents an in-depth analysis of Blinkit (formerly Grofers) sales data using Power BI. It aims to transform raw e-commerce data into powerful, interactive dashboards that      help understand customer behavior, product performance, and business trends.

🔍 Key Features:
    Sales Overview Dashboard: Monitor total revenue, number of orders, average order value, and delivery performance.
    Product & Category Insights: Discover best-selling products, fast-moving categories, and inventory trends.
    Customer Analytics: Track new vs. returning customers, order frequency, and location-based trends.
    Time-Based Trends: Analyze daily, weekly, and monthly sales fluctuations.
    Geo Visualization: Understand city-wise or zone-wise sales performance with map visuals.
